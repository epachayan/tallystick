## Result 1 — The regression, demonstrated

> **SCOPE CORRECTED, 11 August 2026 (RC-H12).** This result is stated over the
> four classes where the principal lies **by assertion** — it asserts something a
> signature contradicts. The corpus contains three further classes with a
> dishonest principal and a correct executor (M13 baseless complaint, M26/M28
> withheld record), and **B1 scores zero on all three, exactly as B0 does.**
> The original denominator excluded them, which flattered B1. The claim holds
> as scoped; see `docs/findings/13-abort-and-declarations.md`.

The thesis predicted that the deployed agentic default cannot let a correct executor defend
itself when the principal lies. Across the four principal-liar classes (M5 repudiation,
M6 narrowed-scope assertion, M7 receipt denial, M9 record alteration), 100 scenarios:

| baseline | correct blame | false accusation | missed |
|---|---|---|---|
| **B0** bearer token + executor log *(deployed default)* | **0** | 0 | **100** |
| **B1** bilateral commitment *(PeerReview-style)* | **100** | 0 | 0 |
| **B2** commitment-only disclosure | 75 | 0 | 25 |
| **B3** B1 + suspected/exposed | **100** | 0 | 0 |

B0 misses every one. Not because it fails to notice a conflict — it does notice — but
because nothing binds either party to a prior position, so the adjudicator has no basis to
prefer one account. The executor's log is self-authored; the principal's denial is
unrebutted. **The conflict is visible and unattributable.**

This is the regression claim as a table rather than an assertion. B0 is not a strawman: it
is OAuth bearer token plus provider-side audit log, which is what is actually shipping.

Aggregate across all 325 scenarios:

| baseline | correct_blame | false_accusation | missed | correct_abstain | correct_abstain_amb |
|---|---|---|---|---|---|
| B0 | 0 | 0 | 250 | 50 | 25 |
| B1 | 250 | 25 | 0 | 25 | 25 |
| B2 | 150 | 0 | 100 | 50 | 25 |
| B3 | 250 | 0 | 0 | 50 | 25 |

## Result 2 — The disclosure boundary is semantic, not structural

Sweeping B1 → B2 (contents withheld; adjudicator sees commitments only):

**Survives:** M3, M4 (record tampering), M5 (repudiation), M7 (receipt denial),
M8 (fabricated authorization), M9 (principal record alteration)

**Dies:** M1 (scope overreach), M2 (omitted action), M6 (narrowed-scope assertion),
M11 (mutual misrepresentation)

The boundary is clean and it is not where I expected. What survives commitment-only
adjudication is everything reducible to **"does this artifact match what you committed
to"** — integrity and existence. What dies is everything requiring the adjudicator to
**interpret meaning**: whether executed actions fell inside a granted scope, whether an
asserted scope is the committed one.

So the cost of withholding disclosure is not a uniform degradation. It is the loss of
*semantic* adjudication specifically, while integrity adjudication is unaffected.

Note **M6 is a principal-liar class that dies under B2**. The disclosure cost is
asymmetric: withholding contents costs the executor part of its defence.

Disclosure cost, mean bytes to the adjudicator:

| baseline | bytes | classes adjudicated | relative |
|---|---|---|---|
| B0 | 245 | 3/13 | 0.60× |
| B1 | 411 | 12/13 | 1.00× |
| B2 | 256 | 9/13 | 0.62× |
| B3 | 411 | 12/13 | 1.00× |

B2 buys a ~38% disclosure reduction for the loss of 3 adjudicable classes. That is the
first real point on the trade-off curve — and it is a much better ratio than the earlier
inference-layer framing suggested.

## Result 3 — Naive bilateral commitment false-accuses (and PeerReview already fixed it)

**This was not predicted and is the most useful thing the run produced.**

B1 false-accuses on all 25 M10 scenarios — benign record loss, where neither party is
dishonest. The reason is structural: a party that *cannot produce* its record is
indistinguishable, to a scheme with a single output state, from a party *concealing* one.
B1 blames the executor for losing a file.

That directly violates the accuracy property the whole thesis rests on. And the fix is
already in the 2007 paper: PeerReview emits **two** states, not one. `exposed` requires a
cryptographic contradiction with something the party previously committed to;
`suspected` covers unresponsiveness, names no wrongdoer, and is withdrawn when the record
appears.

B3 implements the distinction and takes false accusations from 25 to **0** with no loss in
correct blame.

The lesson generalises beyond this harness: **any accountability scheme with a single
verdict state will false-accuse under benign failure.** That is worth stating in the paper
independently of everything else, because the 2026 agentic-audit proposals surveyed
(hash-chained audit logs, delegation receipts) are uniformly single-state.

## Bugs found and fixed

1. **Generator, M4** — `[a for a in actions if a != rng.choice(actions)]` re-evaluates
   `rng.choice` per iteration, so the mutation frequently removed nothing. 5/25 M4
   scenarios were marked `record_intact: False` while carrying content identical to
   ground truth — incoherent. Fixed by selecting the victim once. *A validator asserting
   scenario self-consistency should be added; this bug was only caught by chasing an
   anomalous score.*

2. **Modelling, M10/M11** — M10 conflated record *loss* with record *tampering*. Split via
   a new `record_available` field. M11 was marked unadjudicable, but a committed
   authorization does settle it; reclassified as adjudicable, and a new **M12** added for
   the genuinely unsettleable case (implicit grant, never committed). All four baselines
   correctly abstain on M12, which is the intended behaviour.

3. **Scorer** — a withdrawable suspicion on an honest party was being scored `spurious`.
   It names no wrongdoer and retracts on production of the record, so it now scores
   `correct_abstain`.

## What this does and does not establish

**Does:**
- The deployed default provides no defence to a correct executor against a lying principal — 0/100.
- Bilateral commitment restores it fully — 100/100.
- The disclosure boundary is semantic vs. integrity, cleanly separable, with M6 showing the cost lands asymmetrically.
- Single-state accountability schemes false-accuse under benign failure; the two-state fix is free.

**Does not:**
- No cryptography is implemented. Baselines model what a scheme *could* determine given its
  artifacts; they do not construct or verify signatures. This is an adjudication-logic
  experiment, not a protocol implementation.
- Disclosure is measured as serialized bytes of what reaches the adjudicator. It is a proxy,
  not an information-theoretic measure.
- M-classes are a reconstruction. Reconcile against the authoritative M0–M11 list before
  publication — the split into behavioural / record-tampering / benign-divergence /
  no-commitment families is mine and may not match.
- Two parties only. P5 (equivocation) is absent by design: with one counterparty there is no
  second story to tell.

## Historical next steps

The validator, disclosure sweep, and B4 were subsequently completed. The list below is retained
as the dated plan that led to finding 02; see [what is currently established](../what-is-established.md)
and [finding 02](02-selective-disclosure.md) for the resulting state.

1. **Reconcile the M-class taxonomy** against the authoritative list. Everything downstream
   inherits it.
2. **Add the validator.** Scenario self-consistency checks would have caught bug 1 in
   seconds instead of via score archaeology.
3. **Sweep disclosure properly.** B2 is one point. A parameterised knob — reveal scope but
   not actions, reveal action *count* but not identities, reveal a predicate over scope —
   turns the boundary into a curve. This is the figure the paper wants.
4. **Add B4: selective disclosure via commitments to scope predicates.** If the adjudicator
   can test "was action *a* in the committed scope" without learning the scope, M1/M2/M6
   may come back at near-B2 disclosure. That is the first genuinely open question this
   harness can answer, and it is where a construction would live if one is warranted.
